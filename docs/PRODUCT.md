# Product definition

## Requirement provenance
Confirmed by the owner: a personal knowledge universe / Reasoning Atlas; existing projects represented as skilltrees; physical resources and language knowledge; faithful Windows mockup; Windows + Pi + Git; core integration of the existing skill-based program; desktop AI development; usage-cap handoff; a separate vision/questions space; English as the project language.
Proposed in this blueprint: stack, data contracts, implementation budgets and sequencing. Earlier assistant proposals were not fully accessible.

## Core journey
Capture → understand → connect → investigate → choose → build → verify → remember.
Example: a language-coach idea links language proficiency, a GPU and existing software. Research provides sourced options. A chosen option becomes an Engine proposal. Atlas tracks execution and connects the result and evidence back to the project.

## Research-domain content
The reference includes Mathematical Reasoning, Symbolic Logic, Physics-based Models, Evolutionary Search, Chemical Computing, Meta-Reasoner, Embodied Intelligence and Neuro-symbolic Systems around LLM Reasoning. Preserve these as a synthetic starter research map and support notes, papers, hypotheses and experiments about them.
Do not imply these nodes are functioning reasoning engines. An experiment records hypothesis, method, inputs, result, counterevidence and conclusion. Research-roadmap milestones are knowledge-development stages, distinct from software implementation milestones in ROADMAP.md.

## First release
One user; a Windows desktop browser as the primary client; optional always-on Pi service. Start with a web shell and evaluate native Windows packaging later.
Offline reading and note capture, a sourced map, the Engine read integration and a controlled proposal route are core. Provider independence is an interface requirement; start with one configured provider and fully defined offline behavior.
Exclude autonomous spending, unsolicited publishing, automatic account linking, a replacement Engine implementation and blanket migration of existing applications.

## Success
With a synthetic fixture of 200 nodes and 400 edges, the owner can find a source, understand a prerequisite and draft a build proposal without using a terminal. No input is lost on shutdown. Offline state is honest. Every AI-generated relationship exposes its source and explanation. Performance targets in TESTING.md are targets, not measurements.

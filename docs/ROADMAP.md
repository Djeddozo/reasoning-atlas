# Engine — Vision and Roadmap

## Vision
An always-running system that manages and multiplies everything Djeddi has access to, adapts to new
information faster than anyone else, proposes how to expand, and stays under his control. Personal
first; tangible products and ventures later, each passing through gates before money is committed.

## The eight components
1. **Resource map** — live inventory of money, hardware, accounts, time, skills, contacts.
2. **Loop** — observe → re-evaluate → re-rank → think → log → brief, every hour.
3. **Constitution** — what the Engine may do alone, what needs approval, what is never allowed.
4. **Expansion requests** — when the Engine hits a limit, it calculates what it needs and asks.
5. **Idea engine** — ideas across all of life, scored and moved through gates.
6. **Intake** — voice, links, screenshots and scheduled scans become memory and trigger re-ranking.
7. **Action and approval layer** — does / prepares-for-approval / hands off human-only steps
   (e.g. account sign-up, verification), then operates through official APIs.
8. **Skill acquisition** — finds tools on GitHub, tests them in a sandbox, adopts what works.

## Gates for any project (including physical products)
| Gate | Max spend | Max time | Pass criterion |
|---|---|---|---|
| Idea | €0 | 1 h | Clear benefit, fits resources |
| Test | €50 | 1 week | Real signal (interest, working prototype, measurable result) |
| Build | set per project | set per project | Test signal confirmed |
| Scale | from returns only | — | Build pays for itself |

## Autonomy ladder
Raise limits in `config/constitution.toml` only after the Engine has earned it:
- Phase 0–1: no spending, drafts only.
- Phase 2: proposals each cycle; you accept or reject.
- Phase 4: auto-spend up to €20 per item within a monthly cap; loss-stop freezes everything.

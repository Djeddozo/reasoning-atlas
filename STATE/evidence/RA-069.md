# RA-069 — Voice on the PC's own hardware; hardware as live resources; chat in Quick note

- UTC timestamp: 2026-10-25T15:05Z · Agent: Claude
- Owner (2026-10-25): no Pi CPU for voice (too slow); when Atlas is installed on the PC, heavy functions use the PC's hardware; more voice options in Systems, as easy as possible; hardware resources as active connectors, written ones stay editable; the chat function should work well in Atlas. He prefers the Claude app's own dictation if possible.

## Decisions
- The Claude app's dictation cannot be called by other apps (no public interface). The closest no-key equivalent is the browser's own dictation (already there); the private one is Whisper on the PC.
- Whisper on the PC is installed only when the owner presses Install (his approval for one PyPI package, `pip --user`, optional NVIDIA libraries). Atlas never installs it by itself.
- `pi_whisper_model` stays in config/constitution.toml (only the owner edits that file) but is no longer read.

## Completed
- Engine: Pi CPU tier removed (`models._stt_pi`, `pi_whisper_installed`, voicesetup `pi`, CLI choice); the local tier is a Whisper server only.
- PC: `services/atlas/localvoice.py` (faster-whisper on CUDA float16 or CPU int8, best default model per hardware, settings in runtime/voice.json, recordings removed at once, refused on a Pi); endpoints `/api/voice/local` (+ `/transcribe`, `/settings`, `/install`).
- Quick note 🎙: hearing order This PC → Whisper server → browser, switchable (PC / W / B) and chosen per device under Systems › Voice. Systems gets a Voice tab.
- Resources: `engine/hardware.py` detects OS, CPU, cores, memory, GPUs (nvidia-smi or Windows video controllers) and disk; the Pi reports itself hourly, Atlas on the PC at start, daily and on "Detect this PC now" (hub action `engine.assets.report_hardware`); one live row per machine, read-only, shown under Resources › Connected; written resources stay editable.
- Quick note shows the conversation with Atlas (last six messages, "Whole conversation" opens Notes); filing results still show with Undo.

- Mockups live in the conversation: an open mockup is a Cortex message with Make it in Claude / ChatGPT, Add the mockup, Approve, Set aside; decided ones are one line with Show and Reopen; tasks with a visual side are offered as one Cortex message (Mockup first / Build without).

## Built
- `services/atlas/intake.py`: `sources` and `note_sources` tables (schema version 4, `CREATE TABLE IF NOT EXISTS`).
  - Originals are kept byte for byte in a content-addressed folder next to the database (`runtime/sources/ab/<sha256>`, git-ignored), written atomically (temp file, fsync, rename) before the database row, so a crash can leave at most an unreferenced copy, never a row without its original.
  - SHA-256 is the identity: a repeat import returns the existing source with `duplicate: true` and counts it (`importCount`, `lastImportedAt`); the first name and arrival time are kept as provenance.
  - Validation before anything is stored: empty, over 10 MB, unknown media type, a PDF/PNG/JPEG/GIF/WebP whose bytes do not match, non-printable or empty file names. Paths in names are reduced to the file name.
  - Processing (reading text from text, Markdown, CSV and JSON; images and PDFs are kept, reading them is later work) runs as claim → work → result in separate transactions. States: pending, processing, done, failed (may pass: I/O, missing or damaged original; retried up to 3 times automatically), invalid (content cannot be read as its type; original kept, not retried). Every start resets interrupted `processing` rows and resumes; the owner can retry any source.
  - Notes saved in Quick note are linked to a `note` source holding their exact text; identical texts share one source. Notes saved before RA-005 keep unknown provenance (`sourceId` null), as DATA_MODEL.md requires.
- `services/atlas/server.py`: `GET /api/sources`, `GET /api/sources/<id>` (with extracted text and linked notes), `GET /api/sources/<id>/original` (download, `nosniff`), `POST /api/sources` (JSON with base64 data; 201 new, 200 duplicate, 400 refused), `POST /api/sources/resume`, `POST /api/sources/<id>/retry`; resume runs at every server start.
- Screen (`apps/web/src/main.tsx`): with "This computer" selected in Quick note, 📎 or drag-and-drop keeps the file locally (also when the hub is offline, where it used to refuse); Notes › Local sources lists each file with type, size, imports, status, date (Europe/Paris), short hash, an Original link and Retry when not done.
- `modules/atlas.json`: domain `sources` with `atlas.sources.import`, `atlas.sources.list`, `atlas.sources.resume` (tested, Notes).

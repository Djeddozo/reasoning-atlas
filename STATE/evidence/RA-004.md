## Method
`python scripts/visual_check.py <out>` starts the service on a temporary database, renders the app in headless Chromium at the reference application size (1394 × 855 CSS px, scale 1), crops the reference PNG to the application region from `assets/reference/measurements.json`, and measures each panel's bounding box. It also writes a side-by-side image (green = reference regions, red = implementation) and a 50% overlay.
Environment: Linux, Python 3.13, Node 22, Chromium 140 (Playwright), Segoe UI unavailable so the system sans-serif fallback was used.

## Known deviations from the reference
- Node and navigation icons are text glyphs, not the reference's line pictograms.
- No map toolbar (zoom, fit, fullscreen) and no roadmap "Timeline" selector; no "+" on Quick note.
- Roadmap illustrations are simpler than the reference particles.
- Right-hand satellite labels can clip at the map edge (for example "Automated Program Search").
- Focus status reads "Synthetic" instead of "On track"; tags read "Research concept / Synthetic" instead of "Core / Current State / High Leverage", deliberately, to avoid presenting synthetic content as real status.
- Font is a fallback in this environment; on Windows Segoe UI applies.

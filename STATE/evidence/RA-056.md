## Every function has a home in Atlas
After RA-047 to RA-052, RA-057 and RA-058 every Engine capability the old dashboard offered is also used by Atlas (`use` contains `atlas` in modules/engine.json), each with a note where it lives when it is reached indirectly. The last gap closed here: "Already done?" suggestions from merged work now appear in Today › Waiting on you (keys `S<id>`; Yes, done · Partly · Not related; undoable). ## Why it is not switched off yet
The phone still opens the old dashboard on the Pi (deploy/phone-dashboard.sh). Atlas's own screen runs on the PC only. Switching the dashboard off now would leave the phone without an app, so RA-056 now also waits for RA-031 (local screens on every device, including the phone, through the hub). After that, the switch-off is one owner-approved step.

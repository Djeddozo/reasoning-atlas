## Built
- `hq/export.py`: `snapshot(con, commit)` produces a contract `Snapshot` (sourceKind `engine-export`, exportVersion 1, `readOnly: true`)
  of goals, tasks, skill-tree nodes with computed state and proof, ideas, resources (retired → tombstone), dev runs and research notes.
  It works on an in-memory copy (skill-tree computation seeds nodes; that never reaches the Engine file), reads only listed columns,
  converts local timestamps to UTC `Z`, and raises `SchemaMismatch` when a column it reads is missing.
- Hub function `engine.system.snapshot_export` (GET, read-only connection; 409 `schema_mismatch` on a mismatched database), registered in
  `modules/engine.json` with effect `read` and `viaHub`.
- Adapter: accepts Engine exports by `SUPPORTED_EXPORTS` (export version) instead of a pinned HQ-APP commit; an unknown version is
  `IncompatibleSnapshot`. The pinned-commit path for HQ-APP snapshots is unchanged.
- `services/atlas/enginesync.py`: one allowlisted GET, then the RA-008 import. Every attempt is recorded (`external_sync`), and the state
  is one of connected, stale (> 60 min), offline, unauthorized, schema_mismatch (older Engine without the export, missing columns, newer
  export version), not_configured, never. A failed read keeps the last read model. It lives in services/ because adapters/hq must stay
  free of network code (RA-008 test).
- Atlas service: `GET /api/hq/connection`, `POST /api/hq/sync`; the `/api/health` adapter block reports the state.
- Screen: Systems › Connections (and Systems while the hub is offline) shows the "Engine read model" card: state, message, age,
  Engine commit, counts, and **Read now**.

## No rescore endpoint treated as a pure read
The old dashboard's `GET /api/data` calls `priority.rescore` (writes scores). It is not exposed through the hub. A test runs
`dashboard.build_data` on the hub's read-only connection and shows it fails (`sqlite3.OperationalError`) instead of writing; another
asserts the hub never references `dashboard.build_data`, and that `hq/export.py` contains no rescore, SQL writes, commit, network or subprocess.
